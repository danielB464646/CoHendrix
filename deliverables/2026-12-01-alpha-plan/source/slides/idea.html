CO-HENDRIX IN ONE MINUTE

The LLM writes the music; our code decides what gets applied

1

The producer locks one region (tracks × bars) and asks for an edit in words

2

A cloud LLM proposes exactly one patch for that region

3

Deterministic code checks the region and every confirmed rule

4

Pass: show the change. Fail: up to 3 repairs, then abstain

Guaranteed

Notes outside the region never change. Confirmed rules (key, range, grid) always hold.

Measured, not promised

Musical quality, originality and fit to the producer’s taste.

Works with any DAW

Standard .mid in, standard .mid out. No plugin.

One sentence: generation is untrusted, verification is ours. Step 3 is the core of the project and what the Alpha proves first. The repair loop in step 4 comes after the Alpha (M4).
