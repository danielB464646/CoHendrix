HOW WE WORK · TWO-WEEK SPRINTS, GITHUB KANBAN BOARD

A shared walking skeleton first, then feature ownership

Phase 1 · now → hackathon, 29 Dec

Walking skeleton

The whole team builds the Alpha slice together. Each member builds one layer. The schemas are frozen first.

Phase 2 · January → June 2027

Feature ownership

Each member owns one functional area end to end (UI, logic, tests) and stewards one shared component.

Definition of done

Merged, tests pass in CI, reviewed by a non-author, shown at the sprint review

Mock LLM in CI

Tests are free and repeatable; real Gemini runs are deliberate and logged

AI-assisted code

Allowed only if the author can explain every line, with tests

We rejected pure feature ownership from day one (late integration, risk R6) and pure component ownership (nobody owns user value). The development budget for Gemini is $100 for the year, so CI uses the mock.
